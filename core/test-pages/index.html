Velora Embed — Test Pages

Bezpośrednie testy core JS bundle-u (bez WordPress PHP warstwy).

Hodowca — royal-whiskers-cattery

  • breeder-animals — lista zwierząt z color + tytuły
  • breeder-listings — aktualne ogłoszenia (dostępne kocięta)
  • breeder-posts — aktualności z hodowli
  • breeder-contact — formularz → CRM

⚠ Uwaga: Mioty (litters) to prywatne dane hodowli — nigdy nie są dostępne przez publiczne widgety embed.

Klub — klub-hodowcow-elitarnych

  • club-breeders — lista członków, filtrowalna, sortowalna, switch karty/tabela
  • club-listings — ogłoszenia członków klubu
  • club-posts — aktualności klubu
  • club-events — wystawy i pokazy
  • club-documents — regulaminy, formularze, statut
  • club-contact — formularz z routingiem do działów
